# Bot Teacher — телеграм-бот для курса осознанности

Бот для группового чата курса: следит за домашними заданиями и дедлайнами,
напоминает тем, кто не отметился, и каждый вечер публикует «Итоги дня» —
дайджест с рубриками «Инсайт дня», «Прорыв дня», «Благодарность дня» и т.д.,
собранными по ключевым словам из сообщений участников за день.

## Возможности

- **Домашние задания и дедлайны.** Куратор создаёт задание через `/newassignment`
  (название → описание → дедлайн). Бот публикует объявление с кнопкой
  «✅ Выполнил(а)» — участники отмечаются сами.
- **Напоминания.** За 3 часа и за 30 минут до дедлайна бот пишет в чат, кто ещё
  не отметился. По наступлении дедлайна публикует итоговый отчёт «кто сдал / кто
  нет» и закрывает задание.
- **Итоги дня.** Каждый вечер (время настраивается) бот собирает сообщения чата
  за день и формирует дайджест: сколько было сообщений и активных участников,
  статистика по заданиям с сегодняшним дедлайном и рубрика дня — по одной цитате
  на категорию, если ключевые слова нашлись:
  - 💡 Инсайт дня
  - 🚀 Прорыв дня
  - 🙏 Благодарность дня
  - 💪 Вызов дня
  - ⭐ Гордость дня

  Правила отбора живут в `bot/services/keywords.py` — списки стоп-слов легко
  расширить под лексику конкретного курса.

## Команды

Для всех участников (в группе):

| Команда | Описание |
|---|---|
| `/deadlines` | Список активных заданий и дедлайнов |
| `/status` | Личный статус по активным заданиям |

Для админов/кураторов чата:

| Команда | Описание |
|---|---|
| `/newassignment` | Создать задание (диалог: название → описание → дедлайн) |
| `/report <номер>` | Кто сдал / кто нет по конкретному заданию |
| `/cancelassignment <номер>` | Отменить задание |
| `/setdigesttime ЧЧ:ММ` | Время публикации «Итогов дня» |
| `/settimezone Регион/Город` | Часовой пояс чата (IANA, например `Europe/Moscow`) |
| `/digestnow` | Собрать и опубликовать дайджест прямо сейчас (для проверки) |

Формат дедлайна в `/newassignment`: «сегодня 21:00», «завтра 09:30»,
«15.09 20:00», «15.09.2026 20:00».

## Как это устроено

- **Кто считается участником.** Bot API не даёт ботам полный список участников
  группы, поэтому «известный участник» — это тот, кто хотя бы раз написал в чат.
  Это определяет, кого бот перечисляет как «не сдавших».
- **Хранение данных.** SQLite (через SQLAlchemy async + aiosqlite), файл задаётся
  переменной `DATABASE_PATH`. Сообщения чата хранятся только для формирования
  дайджеста и автоматически удаляются через 7 дней.
- **Планировщик.** Простой фоновый цикл (раз в минуту), без внешних очередей —
  проверяет напоминания, дедлайны и время публикации дайджеста по каждому чату.
  Переживает перезапуск бота, так как всё состояние в базе, а не в памяти.

## Установка и запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. **Важно:** отключите Group Privacy у бота — иначе он не будет видеть обычные
   сообщения в группе (только команды), и дайджест собирать будет не из чего.
   `@BotFather` → `/mybots` → выбрать бота → `Bot Settings` → `Group Privacy` →
   `Turn off`.
3. Добавьте бота в чат курса и сделайте администратором (нужно, чтобы читать
   список админов для проверки прав и в будущем — управлять сообщениями).
4. Установите зависимости:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

5. Скопируйте `.env.example` в `.env` и укажите токен:

   ```bash
   cp .env.example .env
   # отредактируйте .env: BOT_TOKEN=...
   ```

6. Запустите бота:

   ```bash
   python -m bot.main
   ```

```bash
pip install -r requirements-dev.txt

```

## Структура проекта

```
bot/
  config.py                  # конфиг из переменных окружения
  states.py                  # состояния FSM для /newassignment
  db/
    models.py                # SQLAlchemy-модели (Chat, Participant, Assignment, Submission, DailyMessage)
    session.py                # инициализация движка и сессий
  services/
    assignments.py            # бизнес-логика заданий/сдач/отчётов
    deadline_parser.py        # разбор дедлайна из текста
    keywords.py                # рубрики дайджеста и категоризация по ключевым словам
    digest.py                  # сборка текста «Итогов дня»
    message_log.py             # запись/выборка/чистка сообщений чата
    chats.py                   # выборка активных чатов
  filters/admin.py            # фильтр «только для админов чата»
  middlewares/
    db.py                       # сессия БД на апдейт
    registration.py             # авто-регистрация чата и участника
  handlers/
    common.py, tracking.py, assignments.py, digest.py
  background/scheduler_loop.py  # фоновый цикл напоминаний/дедлайнов/дайджеста
  main.py                      # точка входа
tests/                          # pytest-тесты сервисов
```
